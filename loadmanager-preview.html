POWER

Power

Quiet mode makes the laptop quieter while you work, by a quieter power plan or by turning turbo boost off, and puts everything back afterwards.

Quiet mode

Two ways to make the laptop quieter: switch to a quieter power plan (Silent, else Balanced), or keep your plan and only turn turbo boost off and/or lower the maximum processor state in it. Everything is put back when you leave quiet mode, close the app, or after a crash.

Off

Power plans on this computer

Render sessions, auto-start and timed runs use the plan you had before (or the one chosen above), and quiet mode returns when they finish. If you or the laptop's own software change the plan, quiet mode steps aside and does not change it back. Laptop vendor tools (for example ASUS Armoury Crate) may keep their own fan profile; check by ear and with the spike log. A plan can differ in more than speed: on the ROG Zephyrus G14 the Silent plan sleeps and turns the display off after 5 minutes, Turbo after 30. Compare the plans in Windows power options before relying on quiet mode while you are away from the keyboard.

Video

Work folder

Settings for these tools
These apply to jobs started from this window. The lm command line uses its own environment variables.

Copy from the cloud into the work folder

Pick files or whole folders from Google Drive, Dropbox, OneDrive or iCloud. They are copied with a size check, retried if the connection drops, and recorded so that Free space can later delete only copies whose original is still in the cloud.

The check lists what would be copied and whether there is room; nothing is copied.

Make editing proxies

A light copy of every clip in a project, so the editor stays smooth. Clips that already have a proxy are skipped, so a stopped run continues where it left off.

The computer stays awake while it works, and you get a notification at the end.

Encode a video

ffmpeg with sensible settings, using the video chip of this computer when it has a working one. Files in a cloud folder are refused: copy them out first.

More options
Presets write 8-bit video; a 10-bit or HDR input is reported.

Copy results back to the cloud

Copies files into a cloud folder. A file with the same name and size is skipped, a different one is never replaced unless you say so, and your local files stay where they are. The cloud app uploads afterwards.

Free disk space

Removes only what can be made again: local copies of cloud files (when the original is still there with the same size and the copy has not changed) and proxies. Finished renders in the out folder are never touched. Preview first; nothing is deleted until you confirm.

Run a long command and keep the computer awake

Starts the command directly (no shell), keeps the computer from sleeping while it runs, writes a line to the run log and notifies you when it ends. Works for ffmpeg, HandBrake, scripts, n8n jobs, anything. Commands that work on a cloud folder are refused.

Health check

Changes nothing. Looks at free disk space, the power plan, the cloud app, ffmpeg and which video encoders really work on this computer (each is tried for one second).

Claude kit

Makes Claude safe and fast with big video files. It adds a guard that stops Claude from running ffmpeg or HandBrake inside a cloud folder, a skill that teaches Claude this routine, and an lm command for it to use. It changes one entry in Claude's settings.json (a backup is made first) and nothing else.

Restart Claude afterwards so it picks the changes up.

Queue

The buttons above add to the queue while a job runs. If you cancel a job the queue pauses. The choice above is for this time only: it is forgotten after it has happened, and it never fires after a job you cancelled yourself.

LOAD MANAGER / 0.8.0
About
A local process priority and memory manager.
Your data stays here
No account, no analytics, and the process list is never sent anywhere. The recovery journal is stored on this device.
Restoring the original state
A restore button, plus a separate recovery process that runs after a crash. If a restore fails, the entry is kept for the next launch.
Behavior per platform
Windows: priority, efficiency mode and memory trimming for Chrome, Claude, Telegram and Google Drive. macOS and Linux: pausing light background apps only; a pause does not free memory, so the browser and Claude are left alone there.
Not implemented
n8n and mailing control, GPU and temperature monitoring, disk I/O priority, cache cleanup and a mobile remote.
The gain depends on the load
Load Manager gives CPU time to your job and frees memory when it is short. The benchmark shows what changed on this computer. If the limit is disk, GPU or a remote server, there will be no gain. Processes are never terminated and system services are never changed.
